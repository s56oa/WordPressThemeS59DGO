Klasična tema za spletno stran Radio kluba Snežnik Ilirska Bistrica – S59DGO.

== Description ==

S59DGO je klasična, enostolpčna WordPress tema za spletno stran Radio kluba Snežnik Ilirska Bistrica. Vključuje temno modro glavo z grebenom Snežnika, mrežo objav s slikami, temni način po sistemski nastavitvi in tri območja gradnikov v nogi.

== Namestitev ==

1. Videz → Teme → Dodaj novo → Naloži temo → dist/s59dgo.zip.
2. Pred aktivacijo: Videz → Meniji → dodeli meni lokaciji »Glavni meni«.
3. Videz → Prilagodi → Identiteta spletišča → logotip (okrogel, vsaj 200×200) ter po želji »Naslov domače strani« in »Podnaslov domače strani«.
4. Videz → Gradniki → napolni »Noga – Kontakt«, »Noga – Uradne ure«, »Noga – Podpora« (gumb Doniraj kot blok Gumb).
5. Nastavitve → Branje → »Prikaži največ 9 objav«.
6. »Predogled v živo« pred aktivacijo.
